# 接口、数据与环境排查能力

接口与数据方面公开使用 Postman、MySQL 增删改查、日志定位和前端控制台辅助判断；遇到接口返回异常时，会结合这些公开工具和线索排查原因，并辅助判断异常来自前端表现还是后端处理。灰盒与环境方面公开使用 Mobaxterm、Linux 指令、Notepad++ 配置修改，并参与客户环境搭建。
