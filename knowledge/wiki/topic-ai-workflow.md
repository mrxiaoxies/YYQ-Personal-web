# AI 工作流公开概括

个人网站与 Codex 维护工作流：个人网站使用 Vite、React、TypeScript 和 Tailwind CSS 开发，并持续优化中。已完成四季滚动背景、液态玻璃面板、项目进度、简历模块、春夏秋冬掉落物和夏季萤火虫动效。项目建立了 GitHub 发布准备、版本记录、操作文档和 Codex 维护工作流；进行了移动端背景与可读性优化、WebP 背景压缩、按实际使用精简字体，并修复 GitHub Pages 静态资源路径。
项目进度同步：使用 Codex 维护 React / TypeScript 个人网站，完成四季交互、移动端优化、版本发布，并接入管理员登录、栏目编辑、内容保存与修订恢复。
当前阶段：后台管理已接入，持续优化中。已记录里程碑：四季背景切换；花瓣/绿叶/秋叶/雪花；萤火虫轨迹动效；移动端体验优化；首屏背景和字体资源压缩；管理员界面与栏目编辑接入；公开内容与管理员保存接口接入。操作经验：需求拆解与代码定位；React / TypeScript 页面维护；Git 版本管理与发布；GitHub Pages / Netlify 部署；前后端字段与接口验证；后台栏目管理与修订恢复；RAG + Wiki 资料维护与问答验证。待完成：持续补充操作案例，并验证线上内容存储与后台发布链路。。公开范围：已公开。这些记录体现 Codex 辅助实践，不表示每项技术均精通。
自动剪辑工作流项目：分析剪映结构化草稿，使用 FFmpeg 完成竖屏口播视频的素材拼接、缩放裁切、字幕叠加与旁白混音，并检查成片参数、音量和画面。
当前阶段：口播成片流程已验证。已记录里程碑：明确素材导入与整理范围；梳理脚本与镜头拆分步骤；定义字幕与封面输出环节；完成竖屏口播成片生成；核验分辨率、帧率、音频与抽帧画面。操作经验：剪映草稿 JSON 结构分析；素材整理与片段拼接；竖屏缩放裁切；字幕图层与关键词强调；旁白混音与音量检测；成片参数校验与抽帧检查。待完成：继续整理可复用的剪辑风格规则，并验证剪映内打开与导出流程。。公开范围：暂未公开。这些记录体现 Codex 辅助实践，不表示每项技术均精通。
微信 AI 好友本地工作流：PC 桌面微信 AI 好友的 FastAPI 本地后台已发布，PC-only 接入层原型已编写，包含通知、窗口、剪贴板、解析、输入与工作流模块。实现 Windows 通知与当前聊天复制双确认、微信窗口检测、非微信通知过滤、无抢鼠标交互和自动发送安全闸门。当前仍等待真实微信通知完成端到端联调，自动发送保持关闭，不能声称完整消息链路已经验证成功。
