# 测试技能公开概括

银行客服大平台升级维护测试：在中电金信软件担任测试工程师，参与银行客服平台优化升级、业务流程更新和新功能协助测试，并参与 AI 对话平台的电话总结功能测试。可公开概括的工作方法包括使用 Postman 做接口测试、准备测试数据，以及根据日志定位问题原因；不公开客户名称、内部地址、字段、命令、日志原文或真实业务数据。
数据披露双数据源与锁账测试：该项目验证报表生成时的取值方向、双数据源联动逻辑和锁账相关数据条件。公开的测试工作包括使用 MySQL 构造满足条件的数据，验证多表联动取值，并覆盖单逻辑和多逻辑组合。
养老金系统管理测试：该项目围绕养老金业务系统开展流程与数据验证。可公开概括的测试范围包括上传、签发、下载和报表生成流程、金额核对，以及结合数据库逻辑与前端字段进行验证；不公开个人或金融敏感细节、真实金额、字段或表结构。
自研边缘化 AI 工控机测试：在上海蓝涧科技担任研发测试，负责自研边缘化 AI 工控机的机器版本环境搭建、NANO 模块烧录、依赖安装、硬件测试和整机组装测试。公开使用过 Linux 客户环境搭建、jtop 与 stress 压力测试、lsusb 设备兼容识别，并通过脚本优化测试步骤。
广告机不同型号灰盒测试：在上海分众传媒担任项目工程师，测试不同型号广告机，覆盖功能、APK 问题、硬件增减影响、压力测试、直播流推送与指令识别。公开工作包括串口指令测试、配置和验证分辨率与显示关系、使用 VMware 搭建 Linux 测试环境，以及 LoadRunner 性能测试基础实践。
鹰眼系统摄像头测试：在江南造船集团担任软件测试工程师，参与鹰眼系统摄像头业务测试，验证识别、信息调取及通知等流程。使用 Excel 设计测试用例，参与用例评审与执行、Bug 跟踪提交，并辅助判断问题属于前端还是后端；不公开人员信息、内部规则或处理细节。
设备外壳与硬件结构测试：根据图纸设计参与设备外壳钣金焊接和硬件结构测试，提出外壳设计修改建议，并验证硬件密封性、温度和结构。
黑盒与业务流程测试能力：公开的黑盒测试能力包括冒烟测试、边界值、有效等价类、错误处理、UI 界面测试和业务流程测试；环境相关能力还包括弱网测试。网站公开提供一份标准格式测试用例作为测试设计证据。
接口、数据与环境排查能力：接口与数据方面公开使用 Postman、MySQL 增删改查、日志定位和前端控制台辅助判断；遇到接口返回异常时，会结合这些公开工具和线索排查原因，并辅助判断异常来自前端表现还是后端处理。灰盒与环境方面公开使用 Mobaxterm、Linux 指令、Notepad++ 配置修改，并参与客户环境搭建。
