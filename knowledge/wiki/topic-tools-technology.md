# 工具与技术公开概括

技能与工具公开概览：公开资料中可确认的能力包括：黑盒、冒烟、边界值、有效等价类、错误处理、UI、业务流程和弱网测试；接口与数据验证、日志定位、前端与后端问题辅助归因；Linux 客户环境搭建、灰盒、硬件与整机测试；Codex 协作开发、提示词拆解与优化以及 AI 工作流梳理。公开使用过的工具和技术包括 Postman、MySQL、前端控制台、Mobaxterm、Linux 指令、Notepad++、Excel、VMware、LoadRunner、jtop、stress、lsusb、Codex、Builder.io，以及个人项目中的 React、Vite、TypeScript、Tailwind CSS、FastAPI、GitHub Pages 和 Netlify。这里仅汇总公开工作或项目中的使用记录，不表示对每项工具均达到精通程度；具体细节以对应技能和项目条目为准。
银行客服大平台升级维护测试：在中电金信软件担任测试工程师，参与银行客服平台优化升级、业务流程更新和新功能协助测试，并参与 AI 对话平台的电话总结功能测试。可公开概括的工作方法包括使用 Postman 做接口测试、准备测试数据，以及根据日志定位问题原因；不公开客户名称、内部地址、字段、命令、日志原文或真实业务数据。
自研边缘化 AI 工控机测试：在上海蓝涧科技担任研发测试，负责自研边缘化 AI 工控机的机器版本环境搭建、NANO 模块烧录、依赖安装、硬件测试和整机组装测试。公开使用过 Linux 客户环境搭建、jtop 与 stress 压力测试、lsusb 设备兼容识别，并通过脚本优化测试步骤。
广告机不同型号灰盒测试：在上海分众传媒担任项目工程师，测试不同型号广告机，覆盖功能、APK 问题、硬件增减影响、压力测试、直播流推送与指令识别。公开工作包括串口指令测试、配置和验证分辨率与显示关系、使用 VMware 搭建 Linux 测试环境，以及 LoadRunner 性能测试基础实践。
设备外壳与硬件结构测试：根据图纸设计参与设备外壳钣金焊接和硬件结构测试，提出外壳设计修改建议，并验证硬件密封性、温度和结构。
接口、数据与环境排查能力：接口与数据方面公开使用 Postman、MySQL 增删改查、日志定位和前端控制台辅助判断；遇到接口返回异常时，会结合这些公开工具和线索排查原因，并辅助判断异常来自前端表现还是后端处理。灰盒与环境方面公开使用 Mobaxterm、Linux 指令、Notepad++ 配置修改，并参与客户环境搭建。
个人网站与 Codex 维护工作流：个人网站使用 Vite、React、TypeScript 和 Tailwind CSS 开发，并持续优化中。已完成四季滚动背景、液态玻璃面板、项目进度、简历模块、春夏秋冬掉落物和夏季萤火虫动效。项目建立了 GitHub 发布准备、版本记录、操作文档和 Codex 维护工作流；进行了移动端背景与可读性优化、WebP 背景压缩、按实际使用精简字体，并修复 GitHub Pages 静态资源路径。
项目进度同步：使用 Codex 维护 React / TypeScript 个人网站，完成四季交互、移动端优化、版本发布，并接入管理员登录、栏目编辑、内容保存与修订恢复。
当前阶段：后台管理已接入，持续优化中。已记录里程碑：四季背景切换；花瓣/绿叶/秋叶/雪花；萤火虫轨迹动效；移动端体验优化；首屏背景和字体资源压缩；管理员界面与栏目编辑接入；公开内容与管理员保存接口接入。操作经验：需求拆解与代码定位；React / TypeScript 页面维护；Git 版本管理与发布；GitHub Pages / Netlify 部署；前后端字段与接口验证；后台栏目管理与修订恢复；RAG + Wiki 资料维护与问答验证。待完成：持续补充操作案例，并验证线上内容存储与后台发布链路。。公开范围：已公开。这些记录体现 Codex 辅助实践，不表示每项技术均精通。
AI 工具与工作流能力：公开的 AI 工具能力包括 Codex 协作开发、Builder.io 可视化编辑、提示词拆解与优化和 AI 工作流梳理。个人网站体现了用 Codex 维护代码、版本、构建和发布流程；微信 AI 好友项目体现了将 AI 能力放在双确认、风险拦截和自动发送安全闸门之后。
